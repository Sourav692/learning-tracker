## AI Engineer Agentic Track: The Complete Agent & MCP Course (Ed Donner)

- **Link:** https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/
- **Scraped:** 2026-07-24
- **Overview:** 6 sections (weeks) · 145 lectures. 6-week / 8-project agentic engineering course. Strong on Deep Agents (Wk4), Deep Research Agent (Wk2), the Agent Harness + MCP (Wk6), and multi-framework tour (Wk5).

### Week 1 — Foundations, agent loop, context engineering — _31 lectures • 5hr 47min_
- First autonomous agent (n8n no-code); env setup (UV, API keys, GitHub)
- What is an AI Agent? Workflows vs Agents
- Agentic AI design patterns: chaining, routing, orchestrator
- Agentic AI risks, guardrails, evals & traps
- LLM providers compared (OpenAI, Claude, Gemini, Ollama, Groq); call 8 LLMs; local LLMs via Ollama; LLM-as-a-judge
- Agent landscape: frameworks, runtimes, tools, builders; how tool calling works
- Digital Twin: read PDF, system prompts, Gradio chat UI, first tool
- Build the agent loop from scratch (tool calling with a while loop)
- Context engineering for agents: memory, tools, RAG
- Deploy Digital Twin to Hugging Face Spaces; visible agent loop with checklist tools like Claude Code

### Week 2 — OpenAI Agents SDK, orchestration, Deep Research Agent — _23 lectures • 3hr 53min_
- OpenAI Agents SDK core: Agent, Trace, Runner.run; async Python (asyncio)
- Tools with function_tool; memory with Sessions & SQLiteSession
- Multi-agent sales team; orchestrate 3 ways (by code / agents-as-tools / handoffs); asyncio.gather
- Any LLM with the SDK; structured outputs with Pydantic
- Guardrails for agents + sandboxes + MCP
- **Deep Research Agent:** plan it; web-search agent with hosted tools; Planner/Writer/Email agents with structured outputs; run orchestrated by code; modules + Gradio UI; deploy to HF Spaces

### Week 3 — CrewAI — _21 lectures • 3hr 23min_
- CrewAI crews, flows, agents/tasks/crews, YAML; first crew; debate crew
- 5 steps to build any CrewAI project; financial researcher (Serper tool)
- Stock picker: structured outputs, custom tools, memory, hierarchical process
- Coding agent in a Docker sandbox; engineering team (4 agents) with Context7 MCP + UV sandbox tools

### Week 4 — LangChain / LangGraph / Deep Agents / Sidekick — _25 lectures • 3hr 6min_
- LangChain ecosystem (4 layers); core basics; bind tools + structured outputs
- LangGraph: graphs/state/nodes/edges/reducers; LangSmith, supersteps, checkpointers; memory & time travel (MemorySaver, SQLite, replay)
- create_agent: simple agent, memory, structured outputs, middleware
- Browser automation with Playwright MCP; web research agent
- **Deep Agents overview: the agent harness for long-running tasks;** Skills (SKILL.md, progressive disclosure); first Deep Agent with file system & to-do tools; sub-agents (delegation, Task tool); add Skills (PowerPoint via SKILL.md)
- Sidekick: autonomous AI coworker with create_agent; tools, middleware, evaluator; human-in-the-loop (approve/reject); Gradio UI

### Week 5 — Multi-framework tour — _19 lectures • 2hr 5min_
- Google ADK + Agent Development Kit; ADK agent loop with MCP; ADK web dashboard
- **A2A Protocol: Agent Cards + live Agent2Agent demo**
- Strands Agents (AWS/Bedrock); Pydantic AI; Microsoft Agent Framework, AutoGen, Semantic Kernel; Agno; Mastra (TypeScript)
- Agent Loop project: multi-framework architecture (orchestrator/QA/CSS agents; 6 frameworks build in parallel)

### Week 6 — MCP + Agent Harness capstone — _26 lectures • 3hr 20min_
- Welcome to MCP Week: agent frameworks and **the agent harness**
- What is MCP? host/client/server; local vs remote; transports; calling tools
- First MCP lab (Fetch, Playwright, Filesystem); web-browsing agent with MCP + traces
- Build your own MCP server with FastMCP; MCP marketplaces; when NOT to build one
- Context engineering for agents with MCP servers; long-term memory & web-search MCP servers; **Agentic RAG with Qdrant MCP;** market-data MCP + progressive disclosure of tools
- **Capstone: Autonomous AI Trading Floor** — trader/researcher agents; researcher-as-tool; Gradio dashboard; observability/eval/feedback; FastAPI + React ship; trace inspection
- Choosing an agent framework; 10 things that really matter
