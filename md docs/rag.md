## Ultimate RAG Bootcamp Using Langchain, LangGraph & Langsmith

- **Link:** https://www.udemy.com/course/ultimate-rag-bootcamp-using-langchainlanggraph-langsmith/
- **Scraped:** 2026-07-11
- **Overview:** 30 sections · 142 lectures. Krish Naik's deep RAG bootcamp: data ingestion/parsing, embeddings & vector stores (Chroma/FAISS/Pinecone/Astra), advanced chunking, hybrid search & reranking (MMR), query enhancement (expansion/decomposition/HyDE), multimodal RAG, then agentic/autonomous/multi-agent RAG on LangGraph, plus corrective, adaptive, persistent-memory, cache (CAG) and vectorless RAG, guardrails, LLM gateways, RAG evaluation, graph DBs (Neo4j), and an end-to-end project.
